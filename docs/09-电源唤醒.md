# 电源与唤醒

## 设计差异

| 维度 | Linux 思维 | Hib OS 通道思维 |
|---|---|---|
| 睡眠 | ACPI S3/S4，`/sys/power/state`，冻结进程，保存内存到 RAM/磁盘 | 睡眠 = 把全部 `exec::Body` 置为 Suspended，`wait_table` 原样保留，**不丢事件**；唤醒 = `resume_all()`，等待者回到原来的等待键 |

## 通道

| 通道 | 示例 | 说明 |
|---|---|---|
| `power://state` | `act power://state suspend` | 真挂起全部执行体，等待表保留 |
| `power://state` | `act power://state running` / `wake` | 恢复全部执行体 |
| `power://wake-source` | `act power://wake-source irq://timer` | 设置唤醒源；`wake` 时向该通道发 signal |
| `power://wake-source` | `sense power://wake-source` | 查询当前唤醒源 |

- `suspend`：把全部执行体置为 Suspended，`wait_table` 原样保留，不丢事件。
- `running` / `wake`：恢复全部执行体，它们回到原来的等待键上继续。
- 如果设置了唤醒源通道，向其等待者发 `signal` —— 实现「特定事件唤醒系统」。
