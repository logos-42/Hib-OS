# 像素壁纸与桌面应用

真像素 GUI 的桌面环境层：壁纸、任务栏、窗口内运行的应用。

[返回目录](../README.md)

## 像素壁纸（`gui://wallpaper`）

之前合成器只有一套极暗背景，`wallpaper` 命令也只改字符桌面。现在三处入口共用一份状态：

| 入口 | 例子 |
|---|---|
| `wallpaper` 命令 | `wallpaper set sunset`（同时切换字符与像素桌面） |
| `gui` 子命令 | `gui wallpaper set aurora` / `gui wallpaper list` |
| 感知通道 | `sense gui://wallpaper` / `act gui://wallpaper fit tile` |

### 内置风格

`sunset`（默认，日落+山脉）、`aurora`、`circuit`、`nebula`、`grid`、`solid`，外加 `wiki1` / `wiki2` 两张本机真实图片。

摆放方式：`stretch`（拉伸，默认）/ `tile`（平铺）/ `center`（居中）。

### 本机 wiki 的两张图

项目 `.wiki/` 目录里有 `壁纸.png`（1024×1024 RGBA）与 `壁纸2.jpg`（720×720）。第二张已用系统绘图组件预转换为 `壁纸2.png`，两张都走同一个 PNG 解码器：

```sh
act gui://wallpaper wiki           # 列出两张图及可用状态
act gui://wallpaper wiki 1         # 加载 壁纸.png
act gui://wallpaper wiki 2         # 加载 壁纸2.png
wallpaper set wiki1
```

### 图片格式

| 格式 | 支持方式 |
|---|---|
| PNG | `kernel/gui/png.rs` 零依赖手写解码（zlib/DEFLATE 三类块 + 5 种行滤波 + 灰度/RGB/调色板/灰度α/RGBA） |
| BMP | `kernel/gui/bmp.rs` 24/32bpp 解码与导出 |
| JPEG | 暂不直接解码；预转换为 PNG 后复用同一路径 |

```sh
act gui://wallpaper load D:\path\my.png
act gui://wallpaper save D:\path\current.bmp
act gui://wallpaper preview        # 终端真彩色半块字符预览
```

## 真实任务栏（`kernel/gui/taskbar.rs`）

屏幕底部 32 像素，不是画在壁纸上的装饰：

- `APPS` 启动器按钮 + 5 项应用菜单
- 每个窗口一个按钮：焦点高亮、最小化标记
- 右侧状态区（窗口数、当前壁纸名）
- 点击真的改变状态：启动应用、聚焦、最小化/还原

```sh
gui taskbar 20 590       # 点 APPS 打开菜单
gui taskbar 20 460       # 点菜单第一项启动应用
gui shot out.bmp         # 导出画面验证像素
```

## 窗口内运行的应用（`kernel/gui/apps.rs`）

五种应用各有自己的状态，每帧重绘自己的 32bpp 客户端表面：

| 应用 | 行为 |
|---|---|
| `terminal` | 输入命令回车 → 交回内核执行 → 结果回显到窗口 |
| `files` | 列出 VFS 根目录（类型/权限/大小） |
| `monitor` | 实时刷新 uptime / tokens / tasks / VRAM / 帧号 |
| `wallpaper` | 按数字键切换壁纸风格 |
| `notes` | 直接打字，回车换行 |

```sh
gui app monitor
gui app terminal
gui key "sense dev://timer\n"   # \n 映射为 Enter
```

键盘闭环：`input::KeyDown` → 焦点窗口的 `AppState` → 命令经 `Effect::Command` 交给 shell → `gui::app_output()` 回显。

## 验证基线

- 导出的 960×600 BMP 有 `576000` 个非黑像素（壁纸铺满全屏）
- BMP 底部第一行像素为 `1B,11,11`（任务栏底色确实合成进最终画面）
- 两张 wiki 图分别识别为 1024×1024 与 720×720
