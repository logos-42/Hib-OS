# Hib OS 内核扩展路线图（补齐到 20 万行）

## 现状评估
- 源码约 934 KB、79 个 `.rs` 文件，粗略约 2 万行
- 已实现：通道层、五调度域、fiber 用户态线程、GUI、租约/信号量/屏障、VFS 内存树、网络模拟、AI 意识闭环
- 未实现（按 Linux 优先级排序）：

## 阶段 P0：内核基础设施（必须补齐，约 6-8 万行）

### P0-1 虚拟内存管理系统（`kernel/mm/`）
- 页表结构（4 级页表模拟：PGD/PUD/PMD/PTE）
- MMU 模拟：虚拟地址 → 物理地址映射
- 缺页中断：`mem://fault/<pid>/<vaddr>` 通道事件
- 用户/内核地址空间分离（0x0000_0000_0000_0000~0x0000_7FFF_FFFF_FFFF 用户，0xFFFF_8000_0000_0000~ 内核）
- 页框分配器（伙伴系统简化版）
- 写时复制（COW）：租约共享页 + 写时复制
- 交换分区占位框架

### P0-2 进程隔离与 PCB 完善（`kernel/process/`）
- 独立地址空间（每进程独立页表根）
- 进程状态机：创建→就绪→运行→阻塞→僵尸→退出
- fork/exec/waitpid 系统调用（AI 原生：fork = 通道集合克隆，exec = 镜像加载）
- 进程组、会话、控制终端
- 进程资源限制（rlimit）

### P0-3 文件系统 VFS（`kernel/fs/`）
- inode/dentry 树（替换当前简单内存树）
- 文件描述符表（每进程独立 fd 表）
- read/write/open/close/llseek 系统调用
- 挂载点管理（mount/umount）
- 文件锁（flock/posix lock）

### P0-4 块设备层 + 简单文件系统（`kernel/block/` + `kernel/fs/simplefs/`）
- 块设备队列与请求调度
- 简单文件系统（inode 位图 + 数据块，类似 ext2 简化版）
- 缓冲区缓存（buf cache）

### P0-5 系统调用接口（`kernel/syscall/`）
- 真正的 syscall 分发表（不仅是模拟）
- 用户态陷入模拟（trap frame、寄存器保存）
- errno 错误码体系

### P0-6 ELF 二进制加载器（`kernel/loader/`）
- ELF 头解析、程序头段映射
- 动态链接占位框架
- 栈/堆/数据段/BSS 段建立

## 阶段 P1：重要组件（约 6-8 万行）

### P1-1 网络协议栈（`kernel/net/`）
- TCP/IP 协议栈（IP/ICMP/UDP/TCP 简化版）
- socket API（socket/bind/connect/accept/recv/send/close）
- 真实网卡驱动框架（TUN/TAP 或宿主网桥）

### P1-2 设备驱动框架（`kernel/drivers/`）
- PCI 枚举与配置空间读写
- 驱动模块注册/卸载（insmod/rmmod 模拟）
- 设备树 / ACPI 占位框架

### P1-3 多核 SMP 支持（`kernel/smp/`）
- 多 CPU 启动（AP 启动代码占位）
- 自旋锁 + 读写自旋锁
- 处理器间中断（IPI）

### P1-4 页缓存 + 缓冲区缓存（`kernel/mm/pagecache/`）
- 页缓存（文件数据缓存）
- 脏页回写（writeback）
- 缓存压力回收（LRU）

### P1-5 信号机制（`kernel/signal/`）
- 真正的信号（SIGKILL/SIGSTOP/SIGCONT/SIGSEGV 等）
- 信号处理函数注册
- 信号递送与阻塞掩码

## 阶段 P2：增强功能（约 4-6 万行）

### P2-1 交换分区与内存回收（`kernel/mm/swap/`）
- 交换区管理
- 页面换出/换入（LRU/Clock 算法）
- OOM Killer

### P2-2 负载均衡与 cgroup（`kernel/sched/` + `kernel/cgroup/`）
- 多核负载均衡
- 控制组（CPU/内存配额）

### P2-3 审计与日志（`kernel/audit/`）
- 内核审计日志
- kmsg / printk 系统日志

## 总目标
- 从当前约 2 万行扩展到 20 万行
- 每个模块都必须：AI 原生通道接口（sense/act）+ Linux 语义设计 + 单元测试

## 当前优先级顺序
1. 虚拟内存管理系统（P0-1）—— 最基础，没有它无法做进程隔离
2. 进程隔离与 PCB（P0-2）
3. 文件系统 VFS（P0-3）
4. 系统调用接口（P0-5）
5. ELF 加载器（P0-6）
