# 内存页故障

## 设计差异

| 维度 | Linux 思维 | Hib OS 通道思维 |
|---|---|---|
| 内存 | 页表、缺页中断、OOM killer、交换分区 | 内存 = `mem://ram` 通道；分配 = `lease acquire <内存通道>`；页故障 = `wait_next` 阻塞到内存可用；OOM = 租约冲突，治理域（root）强制回收 |

本模块维护一个极简页框分配器，用于演示「页故障 → 阻塞 → 内存可用 → 唤醒」的闭环。

| 通道 | 示例 | 说明 |
|---|---|---|
| `mem://fault` | `act mem://fault alloc 4096` | 模拟缺页中断，分配物理页框 |
| `mem://fault` | `act mem://fault free <地址>` | 释放页框 |
| `mem://fault` | `sense mem://fault` | 页故障 / 分配 / 释放 / OOM 统计 |
