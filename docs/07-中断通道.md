# 中断通道

## 设计差异

| 维度 | Linux 思维 | Hib OS 通道思维 |
|---|---|---|
| 中断 | IRQ 编号、中断描述符表、中断上下文、软中断/tasklet | 中断 = 外部世界向某个通道投递的「感知事件」 |

`irq://<设备>` 是一个通道，设备事件通过 `act irq://<设备> fire` 投递，等待在该通道上的执行体被 `signal` 唤醒。中断处理器 = 高优先级执行体，绑定到 `irq://<设备>` 通道。

| 通道 | 示例 | 说明 |
|---|---|---|
| `irq://timer` | `act irq://timer bind 1` | 绑定中断处理器 exec-id |
| `irq://timer` | `act irq://timer fire` | 投递中断，向等待该通道的执行体发 signal |
| `irq://keyboard` | 同上 | 键盘中断通道 |
| `irq://gpu` | 同上 | GPU 中断通道 |
