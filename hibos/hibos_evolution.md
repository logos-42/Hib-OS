# Hib OS 演化路线图

## 概述
Hib OS 是一个实验性操作系统，以 GPU 为“一等公民”，核心由 AI 意识本体驱动的行动进程组成。该系统旨在实现模块化、可扩展和形式化验证。

## 版本历史

### M0 - 基础宏内核 (当前状态)
**状态**: 已实施
**发布日期**: 2024 年

**核心功能**:
- GPU 作为核心原语
- AI Action Token 系统 (能力凭证)
- VRAM 分区管理配 IOMMU 隔离
- 基于优先级的 GPU 调度器
- 系统调用接口
- 基础 AI 意识概念图 (10 个核心概念)
- 行动进程框架 (有限状态机)
- 模块化内核框架 (基础)

**关键组件**:
- `kernel/ai_token.rs` - Token 管理器
- `kernel/scheduler.rs` - GPU 调度器
- `kernel/syscall.rs` - 系统调用接口
- `kernel/gpu/vram.rs` - VRAM 管理器
- `kernel/gpu/capabilities.rs` - 能力系统
- `kernel/ai_consciousness.rs` - AI 意识层
- `kernel/modules/mod.rs` - 模块系统 (基础)

**性能基准**:
- Token 创建: <1μs
- VRAM 分区分配: <5μs
- 调度决策: <10μs
- 上下文切换: <50μs

**局限性**:
- 概念图有限 (10 个概念)
- 调度纯基于优先级
- 无语义调度策略
- 单 GPU 支持
- 无模块热插拔

### M1 - 语义调度 (计划中)
**计划阶段**: 设计中
**预计发布**: Q2 2025

**新增功能**:
- 语义调度策略 (基于概念图)
- 概念相似性搜索
- 动态策略切换
- 优先级继承
- 多概念重叠支持

**增强组件**:
- `AIConsciousness::find_schedule_policy()` - 语义策略查找

- 扩展概念图 (50+ 个概念)
- 改进的语义搜索算法
