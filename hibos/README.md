# Hib OS

GPU-Centric 宏内核原型：把系统资源（文件、显存、设备、网络、桌面…）统一建模为"通道"的操作系统内核，并内置 **AI 意识本体闭环**（感知 → 思考 → 行动）。

## 一句话总结

> 一切都是 AI 意识的**感知通道（sense）**与**行动通道（act）**。并发与调度围绕通道建模，而非线程；资源是 AI 意识的"感知通道 / 行动通道"，并发与调度围绕通道而非线程建模。
